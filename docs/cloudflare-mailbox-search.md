# 单邮箱缓存邮件搜索网页

## 范围

功能清单要求单邮箱和聚合收件箱都能搜索、分页及按时间和发件人筛选。
原单邮箱页面只有刷新、分页与验证码提取；普通缓存邮件搜索后端已经存在。
本增量只补齐自营／临时邮箱的单邮箱阅读页面，不改变独立普通邮箱账号页面。

## 实现边界

- `MailboxMessageSearch.tsx` 负责关键词、发件人、本地收件时间范围和清除表单。
- `useMailboxMessages.ts` 负责缓存读取、显式同步、分页及异步结果的代次隔离。
- `MailReader.tsx` 保留邮件展示、详情和验证码提取接线。
- 无筛选仍使用既有单邮箱列表和原 ID 游标，不改变原分页合同。
- 有筛选复用既有聚合查询，固定当前 `mailboxId` 和 `folder=all`；包含归档但不含回收站，不查询其他邮箱。
- 筛选首屏另外读取既有单邮箱列表的 `limit=1`，取得真实同步时间、错误与上游续页信息。
  这只是缓存读取，不连接供应商；筛选分页不重复读取该元数据。
- 搜索、清除及分页不隐式同步；只有显式刷新或既有提取等待可以触发原收件业务。
- 暂停同步不禁止搜索既有缓存。显式同步后保留当前筛选，重新从首屏读取。
- 新查询、隐藏页面及卸载会使旧查询／分页／同步的迟到结果失效，不自动重放同步。
- 时间按浏览器本地时区转换为秒；无效或倒置范围在发请求前拒绝。

## 验证入口与非目标

```powershell
node --test --test-concurrency=1 tests/mailbox-search-web.test.mjs
```

测试覆盖正文关键词、特殊字符、发件人、时间、精确邮箱归属、归档可见、分页、清除、阅读、暂停后的缓存搜索、
非法范围、迟到首屏／分页、旧列表续页同步状态更新、显式同步后保留筛选和移动端宽度。
已有的邮件阅读、同步、聚合搜索、生命周期、提取、附件、到期和发送测试仍须关联回归。
测试输出目录必须通过 `EASYEMAIL_TEST_ROOT` 指向隔离的本地临时目录。

本增量不新增服务、API、数据库迁移、依赖或定时任务，不开放公网，不设置真实密钥，
不操作真实供应商，不导入生产邮件，也不表示 Cloudflare 部署或真实邮件验收完成。
