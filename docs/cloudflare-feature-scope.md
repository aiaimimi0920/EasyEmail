# Cloudflare Web 功能确认清单

本清单记录用户在 2026-10-28 确认的目标。它描述要交付的产品能力，
不表示这些能力已经全部迁移或通过验收。阶段顺序不是取消后续功能。

本页后面的初始阶段安排保留为历史规划，不能用其中“未完成”推断当前代码状态。
最新供应商进度见 [迁移覆盖表](cloudflare-provider-coverage.md)，各能力切片与本地验收入口见 [迁移计划](cloudflare-migration.md)。

## 1. 产品边界

- Cloudflare Email：自营临时邮箱供应商，负责地址、收信、原始邮件及附件。
- Cloudflare EasyEmail：聚合自营和第三方邮箱，提供用户 Web 页面及开放 API。
- Web 与程序接口复用相同业务规则、权限和数据访问边界。
- 用户不需要安装桌面端、Userscript、本地 Node 或 NAS 服务。
- 桌面和 Userscript 不再是目标产品形态；旧源码保留为复用及迁移参考，暂不删除。
- 最终目标不以 NAS 为运行前提；过渡期保留现行服务，不自动退役。

## 2. Cloudflare Email

| 功能 | 目标与限制 |
| --- | --- |
| 域名 | 可用域名、域名启停、地址前缀规则；按需使用随机子域名 |

| 收信 | 解析信封、头部、正文、附件，保留可追溯的原始来源 |
| 查询 | 分页、详情、筛选、附件下载、删除 |
| 发信 | 仅使用已授权且已配置的发送身份与渠道，受配额和反滥用规则限制 |

| 接口 | 为聚合平台及获授权的独立调用方提供稳定邮箱 API |

复用 `upstreams/cloudflare_temp_email`，不默认重写收信入口和现有后台。
保留现有独立页面作为迁移输入，但不重复建设两套综合聚合工作台。

## 3. Cloudflare EasyEmail 第一阶段

### 供应商与邮箱

- 接入自营 Cloudflare Email、Temporam，并逐步迁移其他已有供应商。
- 支持多实例、能力查询、状态、手动选择与自动选择策略。
- 保留健康检查、失败退避和冷却；不能静默替换已经分配的邮箱地址。
- 创建、列表、详情、名称或备注、收藏、刷新、停用、释放和删除。
- 供应商支持且所有权有效时恢复访问；明确不可恢复及已过期状态。
- 收藏或纳入常用邮箱不改变上游有效期，不承诺第三方临时邮箱永久可用。

### 收件与提取

- 单邮箱与聚合收件箱，分页、搜索、时间和发件人等筛选。
- 文本及安全处理后的 HTML 阅读、附件查看和下载、来源及同步状态。
- 验证码与认证链接提取、近期记录、按条件查询和等待新结果。
- 依据收件地址、发件人、主题和时间约束匹配，不返回陈旧验证码冒充新结果。
- 展示或复制认证链接，不默认访问；邮件内容不能直接授权程序执行。
- 基础已读、星标、归档和删除，区分平台状态与远端状态。

### 基础发信

- 自营及已支持供应商的写信、回复、发送状态和失败原因。
- 不强求只读供应商支持发信，不允许冒用其他供应商地址。
- 区分请求受理、渠道接收和已知投递结果；未知结果不盲目重发。
- 复杂队列、附件发送和定时发送在后续工作台阶段完善。

### 用户、接口与后台

- 第一阶段登录后使用，具有多用户数据隔离；暂不开放匿名访客邮箱。
- Web 登录与程序 API Key 分离，共享权限规则，不共享管理员权限。
- API 覆盖供应商能力、邮箱管理、邮件、提码、认证链接及可用发信能力。
- API 提供明确错误码、分页、增量查询、限流及必要写操作防重复机制。
- API Key 可创建、撤销及限制权限；所有资源操作校验用户归属。
- 初期由平台统一配置供应商凭据，用户自带供应商 Key 留作扩展。
- 管理后台提供供应商、域名、凭据、配额、状态、脱敏日志及数据保留管理。

## 4. 后续工作台与独立模块

| 模块 | 保留目标 |
| --- | --- |
| 完整邮件工作台 | 文件夹、标签、批量整理、会话、订阅邮件、联系人 |
| 完整写信 | 抄送、密送、云端草稿及跨设备恢复、真实附件传输 |
| 可靠投递 | 定时发送、持久化队列、受控重试、取消与结果追踪 |
| 普通邮箱 | 账号配置、连接测试、凭据管理、收件同步、邮件操作和授权发信 |
| Agent 邮件 | 独立账号与权限、任务邮件、回复关联、线程、信任及人工关注状态 |

普通邮箱和 Agent 邮件保留在整体目标中，独立迁移，不阻塞第一阶段临时邮箱上线。
其 Cloudflare 协议适配、运行限制和成本需要逐项验证，不能以账号页面代替业务验收。

Telegram、推送、更多第三方登录、Passkey、AI 分析和自动头像作为扩展候选，
不是第一阶段完成门槛。未确认取消现有上游能力，也未授权删除其代码。

## 5. 不当作已完成能力迁移的预览入口

- 桌面附件暂存不等于附件已上传或可发送。
- 邮件加密预览不等于真正加密投递。
- 有效期标记不等于能删除外部收件箱中的邮件。
- 开发用平台账号预览不是生产身份体系。

这些入口只有在另行明确产品语义并实现后才能对外启用，不能展示虚假成功状态。
